04 / PRINCIPLES

Designed with restraint

Less dashboard.
More instrument.

01

Fast before fancy

The first useful action stays obvious. Advanced controls remain one gesture away, not one screen in the way.

02

Readable by default

Every short link can carry meaning through a deliberate slug, label, and destination preview.

03

Measure without spying

The production backend records coarse country, device, referrer, and time—never visitor IPs in the app database.

04

Portable architecture

Static UI on GitHub Pages. Edge redirect service and SQLite-compatible analytics on Cloudflare when you want real sharing.
